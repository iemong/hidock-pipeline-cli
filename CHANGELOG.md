# Changelog

## 0.1.0

Initial public release. Extracted from a private personal pipeline
repository — see the [README](README.md) for setup.

- Pull meeting recordings off a HiDock P1 over USB
- Transcribe and summarize with Gemini via Vertex AI
- Write notes to a configurable folder (e.g. an Obsidian vault)
- `hidock --list` / `--all` / `<name fragment>` CLI
- `HIDOCK_DEVICE=replay` mode for trying the CLI without a real device
